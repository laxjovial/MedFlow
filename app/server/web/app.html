Backups

Off-site cloud copy

An extra copy of your records in cloud storage that you own — MedFlow never hosts them and never charges you for space. Two ways to switch it on:

  • Guided: click Set up with a helper account — we walk you through creating storage with a friendly provider in a few clicks, then bring the details back here.
  • Already have storage? Fill in its web address, folder name and your access keys below. Ask whoever set up your internet or office computers if unsure.

Every copy is scrambled with a secret phrase that only your facility knows — the storage company can't read a word. MedFlow never stores the phrase; if it's lost, the off-site copies cannot be opened.

Storage help, step by step

What to paste where: Endpoint is the storage's web address · Bucket is the folder name you created there · Access key + Secret are the username-and-password pair the storage shows you after setup. Everything is saved on this computer — nothing is sent to us.
